# MyBourse

Application web TypeScript pour visualiser et comparer des actions boursières, avec graphique interactif, gestion d'erreurs, mode sombre et export CSV.

## Lancement du projet

1. Accéder au dossier du projet.
2. Installer les dépendances : `npm install`.
3. Lancer le serveur de développement : `npm run dev`.
4. Accéder à l'application.

Ouvrir le navigateur à l'adresse indiquée dans le terminal (exemple : `http://localhost:5173`).
